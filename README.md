# CGV 용산 IMAX 오디세이 Discord 알림기

CGV 용산아이파크몰에서 **오디세이(영화번호 `30001323`)의 IMAX 회차가 새 날짜에 처음 등록되면** Discord로 알려줍니다.

- PC가 꺼져 있어도 GitHub Actions에서 계속 실행
- 1분 간격 확인
- CGV 일반/4DX 회차를 제외하고 실제 IMAX 회차만 감지
- 회차 시간과 알림 시점의 잔여 좌석 표시
- 같은 날짜의 중복 알림 방지
- Discord 전송 실패 시 날짜를 처리 완료로 기록하지 않아 다음 확인 때 재시도

## 준비물

1. Discord에서 알림을 받을 서버 채널을 만듭니다. 혼자만 볼 채널이어도 됩니다.
2. 채널 설정 → **연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사**를 선택합니다.
3. 이 프로젝트를 **공개 GitHub 저장소**에 올립니다. 공개 저장소의 표준 GitHub Actions 러너는 무료이며, 비공개 저장소에서 24시간 감시하면 무료 실행 시간을 빠르게 소진합니다.
4. 저장소 **Settings → Secrets and variables → Actions → Secrets**에서 다음 값을 추가합니다.

   - 이름: `DISCORD_WEBHOOK_URL`
   - 값: 복사한 Discord 웹후크 URL

웹후크 URL은 비밀번호처럼 취급해야 하며 코드, 커밋, 채팅에 올리면 안 됩니다.

휴대폰 푸시를 확실히 받고 싶다면 같은 화면의 **Variables** 탭에 `DISCORD_USER_ID`를 추가합니다. 값은 본인의 Discord 사용자 ID 숫자입니다. Discord 개발자 모드를 켠 뒤 본인 프로필에서 **사용자 ID 복사**로 얻을 수 있습니다.

## 최초 실행과 테스트

1. 저장소의 **Actions** 탭에서 `CGV 용산 IMAX 감시`를 엽니다.
2. **Run workflow**를 누르고 `Discord 테스트 알림만 1건 보내기`를 체크해 실행합니다.
3. 알림이 오면 다시 **Run workflow**를 누르되 체크하지 않고 실행합니다.

첫 정상 실행은 이미 열려 있는 IMAX 날짜를 기준선으로 저장하고 `감시를 시작했습니다` 메시지를 보냅니다. 이후 새 날짜의 IMAX 회차가 등록될 때만 예매 알림이 옵니다.

## 동작 방식

CGV 예매 페이지가 사용하는 조회 API를 크롬과 같은 TLS 지문으로 호출합니다. 일반 서버 요청은 CGV의 Cloudflare 차단에 걸릴 수 있어 `curl_cffi`를 사용합니다. GitHub 예약 실행의 지연을 줄이기 위해 하나의 작업이 약 5시간 40분 동안 1분 간격으로 확인하고, 다음 예약 작업이 이어서 실행됩니다.

Discord 웹후크는 서버 채널로 메시지를 보내며 사용자 DM으로 직접 보내지는 않습니다. 혼자만 볼 채널과 `DISCORD_USER_ID` 멘션을 함께 쓰면 개인 알림처럼 사용할 수 있습니다.

## 주의

이 도구는 예매 오픈 여부만 확인하며 자동 예매를 하지 않습니다. CGV 페이지나 차단 방식이 바뀌면 수정이 필요할 수 있습니다. 10회 연속 조회 실패 시 Discord로 오류 알림을 보냅니다.
